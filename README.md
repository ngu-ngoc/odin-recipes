# Odin Recipes

This project contains my code for the [Recipes Project](https://www.theodinproject.com/lessons/foundations-recipes) in the [Foundations Course](https://www.theodinproject.com/paths/foundations/courses/foundations) of [The Odin Project](https://www.theodinproject.com/). This project allowed me the opportunity to practice the following concepts:

- Setting up a basic project.
- Using basic HTML to structure and link multiple pages together.
- Performing a deployment of a simple HTML website.
